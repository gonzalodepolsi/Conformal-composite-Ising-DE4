# Supplementary notebook

This repository contains a notebook with analytical expressions accompanying the article:

**Convergence of the conformal Ward identity in the derivative expansion approximation**  
Jorge Ibañez, Matthieu Tissier, and Gonzalo De Polsi (2026).

**Preprint:** [arXiv:2608.25103](https://arxiv.org/abs/2608.25103)

## Overview

The article studies conformal Ward identities in the three-dimensional Ising universality class within the functional renormalization group, using the derivative expansion through order $O(\partial^4)$ and $\mathbb{Z}_2$-invariant composite operators.

The notebook provides the accompanying analytical expressions in electronic form.

## Usage

Download the notebook and consult it alongside the article, which provides the theoretical framework, definitions, and conventions.
